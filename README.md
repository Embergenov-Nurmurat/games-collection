# Mini Games — Android (Kotlin)

Одно приложение — **десять игр**: Flappy Bird, крестики-нолики, шахматы, шашки, четыре в ряд, нарды, 2048, судоку, сапёр и морской бой.
Нативный Android на Kotlin, без внешних библиотек: всё рисуется на Canvas (без картинок и шрифтов-ассетов), звуки и фоновая музыка синтезируются в коде.
Языки: English, Русский, O‘zbekcha (по умолчанию — язык телефона). Тема: авто / тёмная / светлая.

## Как открыть
1. Распакуйте zip.
2. Android Studio → **File ▸ Open** → выберите папку `MiniGames`.
3. Дождитесь Gradle Sync (Studio предложит скачать Android SDK Platform 34 и Gradle 8.7, если их нет).
4. **Run ▶** (эмулятор или телефон с отладкой по USB).

Требования: Android Studio Hedgehog (2023.1) или новее, JDK 17 (встроенный JDK Studio подходит), minSdk 21 (Android 5.0), compileSdk/targetSdk 34.
Сборка APK из консоли: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/`.

## Игры
- **Flappy Bird** — 3 сложности, подвижные трубы, монеты, образы (открываются по рекорду, монетам и серии «вызова дня»), 4 пейзажа, «Вызов дня» (одинаковые трубы для всех в один день, серия дней), щиты (опция).
- **Крестики-нолики** — 3×3 и 5×5, против компьютера (3 уровня) или вдвоём, счёт серии, подсказка, отмена, таймеры, продолжение партии.
- **Шахматы** — полные правила; компьютер на 3 уровнях и быстрый режим; выбор стороны; подсказка, отмена; часы; режим «лицом к лицу» (фигуры чёрных повёрнуты); сохранение партии; запись ходов (SAN) и PGN через «Поделиться»; название дебюта (книга из 39 дебютов); разбор партии с графиком оценки и поиском ошибок; 54 мат-задачи (мат в 1–3 хода).
- **Шашки** — три набора правил: русские 8×8, международные 10×10 (взятие большинства) и поддавки; обязательное взятие, летающие дамки, серии ударов; 3 уровня, подсказка, отмена, часы, f2f.
- **Четыре в ряд**, **Нарды** (короткие), **2048** (отмена хода, рекорды), **Судоку** (3 сложности, пометки, подсказки, подсветка ошибок), **Сапёр** (3 уровня, флажки, безопасный первый ход), **Морской бой** (расстановка перетаскиванием, 3 уровня ИИ, «попал — стреляешь снова»).
- **Общее:** 29 достижений, статистика на главном экране, звук, вибрация, фоновая музыка (по умолчанию выключена), адаптивная иконка (в т.ч. тематическая для Android 13+).

## Структура
```
app/src/main/java/com/example/minigames/
  MainActivity.kt       — окно, immersive-режим, переключение экранов, музыка, жизненный цикл
  GameStrings.kt        — регистрация таблиц текстов всех игр (новая игра добавляет свою таблицу сюда)
  core/                 — BaseView (цикл 60 Гц, кнопки, рисование), TableGameView-основа, I18n, Store, Sfx,
                          MusicSynth/MusicPlayer, Achievements, Clay (стиль иконок), Host
  hub/HubView.kt        — главный экран, достижения, настройки
  <игра>/               — движок (чистый Kotlin, без Android), экран (*View), тексты (*Strings), иконка (*Icon)
res/                    — иконка приложения (vector, adaptive + monochrome + круглая), названия приложения (EN/RU/UZ)
```
Движки не зависят от Android, поэтому тестируются на обычной JVM.

## Как добавить язык или текст
Все строки: `core/I18n.kt` (общие) и `<игра>/<Игра>Strings.kt` (`"ключ" to arrayOf("English", "Русский", "O‘zbek")`), в коде — `t("ключ")` / `t("ключ", аргументы)` (`{0}`, `{1}` заменяются аргументами). Узбекский — латиницей с апострофом U+2018 (o‘, g‘). Название приложения — в `res/values*/strings.xml`.

## Что проверено, а что нет
**Проверено (в песочнице без Android SDK):**
- type-check всего проекта (Kotlin 1.9) против заглушек Android API — 0 ошибок;
- JVM-тесты движков: перфт шахмат и шашек (русские, международные, поддавки), шахматные задачи/разбор/PGN, 4 в ряд, нарды, 2048, судоку, сапёр, морской бой, синтезатор музыки и логика плеера на заглушках;
- проверка переводов (`tests_i18n`): 245 ключей + 29 достижений — по 3 непустых перевода, одинаковые `{n}`, узбекский латиницей, все `t("…")` в коде есть в таблицах, число аргументов совпадает;
- сценарные тесты «нажатиями» на Java2D-рендере (все игры, тёмная и светлая тема, EN/RU/UZ) и скриншоты.

**Не проверено:** приложение ни разу не собиралось настоящим Gradle/Android SDK и не запускалось на устройстве или эмуляторе. Не оценивалось на слух реальное звучание музыки/звуков, реальные маски иконки в лаунчерах, поведение на разных размерах экрана и при входящем звонке (аудиофокус не запрашивается). Скриншоты — приближение на Java2D, а не снимки с телефона. Если Studio покажет ошибки сборки, пришлите текст ошибки.
