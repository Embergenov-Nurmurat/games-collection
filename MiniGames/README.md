# Mini Games — Android (Kotlin)

Одно приложение — четыре игры: **Flappy Bird**, **крестики-нолики**, **шахматы** и **шашки**.
Нативный Android на Kotlin, без внешних библиотек (Canvas + SoundPool). Языки: English, Русский, O‘zbekcha.

## Как открыть
1. Распакуйте zip.
2. Android Studio → **File ▸ Open** → выберите папку `MiniGames`.
3. Дождитесь Gradle Sync (Studio сама предложит скачать Android SDK Platform 34 и Gradle 8.7, если их нет).
4. Нажмите **Run ▶** (эмулятор или телефон с включённой отладкой по USB).

Требования: Android Studio Hedgehog (2023.1) или новее, JDK 17 (встроенный JDK Studio подходит), minSdk 21 (Android 5.0).
Сборка APK из консоли: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/`.

## Игры
- **Flappy Bird** — 3 сложности, подвижные трубы, монеты, скины (открываются по рекорду), тема день/ночь/авто.
  Режим **щитов выключен по умолчанию**: включается в *Настройках* Flappy Bird (кнопка «Щиты»).
- **Крестики-нолики** — поле 3×3 (3 в ряд) или 5×5 (4 в ряд); против компьютера (3 уровня) или вдвоём; счёт серии партий, подсказка, отмена хода.
- **Шахматы** — полные правила (рокировка, взятие на проходе, превращение, пат, мат, 50 ходов, троекратное повторение, недостаток материала);
  компьютер на трёх уровнях, выбор стороны (поле переворачивается за чёрных), подсказка, отмена, взятые фигуры, подсветка ходов.
- **Шашки** — русские: обязательное взятие, дамка летает, взятие назад, серии ударов (с выбором пути), превращение прямо во время удара; 3 уровня, подсказка, отмена.
- Общее: язык (EN/RU/UZ, по умолчанию — язык телефона), звук и вибрация, статистика побед/поражений на главном экране.

## Структура
```
app/src/main/java/com/example/minigames/
  MainActivity.kt        — окно, immersive-режим, переключение экранов
  core/                  — BaseView (цикл 60 Гц, кнопки, рисование), I18n (переводы), Store, Sfx, Host
  hub/HubView.kt         — главный экран и общие настройки
  flappy/                — Flappy Bird
  table/TableGameView.kt — общая основа настольных игр (меню, уровни, итоги, статистика, ИИ в фоне)
  tictactoe/ chess/ checkers/ — движки (чистый Kotlin, без Android) и экраны
```
Движки не зависят от Android, поэтому легко тестируются на обычной JVM.

## Добавить язык или текст
Все строки лежат в `core/I18n.kt` (`"ключ" to e("English", "Русский", "O‘zbek")`). Название приложения — в `res/values*/strings.xml`.
